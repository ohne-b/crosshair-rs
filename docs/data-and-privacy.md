# Data and privacy

Crosshairs, profiles, shortcuts and settings stay on your computer. Open their
folder through **Settings > Data > Open folder**. Installed and unpackaged builds
use separate data folders.

## Back up and restore

Use **Settings > Data > Export all** to save a backup outside the app's data folder.
Use **Import** to add crosshairs or profiles; **Replace all** restores an all-data
export over the current collection and settings.

Updates keep your data. Uninstalling removes the installed app's local data, so
export first. Quit through the tray before copying or editing the data folder.
Keep backups private: they can contain names and imported images.

## Network and input

There are no accounts, cloud sync or telemetry. Automatic update checks contact
GitHub and can be disabled in Settings. You can also check manually. Downloads
start only when requested. Opening external links uses your browser.

Discord Rich Presence is optional and on by default. Disable it in Settings >
General > Show activity on Discord. When enabled, the engine
sends the overlay's visible/hidden status or the fixed Soldier: 76 quote to the
local Discord desktop client, which shares it according to your Discord Activity
Sharing settings. It also sends the app logo's asset key and the project's releases link.
Crosshair names, designs, profiles and input are never sent. There are no image
uploads, accounts, tokens or additional network services in this integration.

Keyboard and mouse shortcuts are observed globally without blocking or injecting
input. The app does not record a history of your keystrokes. Xbox Game Bar is a
separate Microsoft application with its own privacy settings.
