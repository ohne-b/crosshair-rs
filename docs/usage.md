# Editor and shortcuts

## Crosshairs

Create a crosshair in **Crosshairs**, then open it in **Designer**. Add layers for
crosshair lines, shapes, images or drawing. Changes save automatically.

Drag layers to reorder them. Use the eye to hide a layer and the trash can to
delete it. Backspace deletes selected layers when you are not editing a text field.
Scroll over the canvas to zoom; hold the middle mouse button to pan. Canvas zoom
does not change the overlay's size.

Rename crosshairs directly in their name fields. Star favorites to find them again.
Profiles group crosshairs and shortcuts; choose a profile in the header and manage
them under **Settings > Data**.

## Shortcuts

Open **Keybinds** and add a crosshair shortcut or a press/hold action. Select the
recording control, then press the keyboard key or mouse button you want to use.
Mouse-wheel bindings support press actions only.

Shortcuts work in every app, including while typing. The same input still reaches
the foreground app. There is no game detection or automatic profile switching.

Use the header switch to show or hide the crosshair. Its tooltip shows the current
shortcut; the default is **Shift+Alt+Z** on a US keyboard layout.

## Closing and startup

Closing the editor leaves the crosshair running. Reopen it through the tray's
**Open menu** action. **Quit** stops the whole app.

**Settings > General > Launch at sign-in** starts the overlay without opening the
editor. Adjust the monitor, position and output scale in **Settings > Display**.
